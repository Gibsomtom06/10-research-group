## High-level synthesis (captured from chat response, April 22 2026)

### Income architectures (the 3 recurring bets)
1. **Zero-Risk Retail AI Arbitrage** — local models find clearance flips, execute low-capital trades
2. **Automated Micro-SaaS / Website-as-a-Service** — hyper-niche tools shipped on a pipeline
3. **Faceless Media / Affiliate Channels** — agent-operated content + affiliate monetization

### Agent design patterns (the recurring primitives)
- **Supervisor Loop** — oversight agent routes/verifies specialists
- **Plan-Execute-Summarize (PES)** — traceability pattern, each step logged
- **Reversible Reasoning** — agents can backtrack on errors without state loss

### Cost guidance — these are OUR PRICES to clients, not our build costs

10 Research Group operates as an AI agent agency / factory. The bands below are what we CHARGE:

- **MVP agent build: $25K–$50K** (single-domain agent system, 4-8 week delivery)
- **Enterprise agent system: $150K–$300K+** (multi-agent orchestrated platform, 3-6 month delivery)
- **Zero-cost path:** local open-weight models (Ollama / OpenClaw) when building for ourselves or on performance-share pilots

### Client engagement ladder (how we get FROM here TO charging the bands)

1. **Client 0 — Performance-share pilot (the Rim Shop).** Zero upfront, we get paid above wholesale. Proves the factory works. Generates the case study.
2. **Clients 1-3 — Discounted MVP ($10K-15K with case-study rights).** Priced to close fast, builds pipeline of proof points.
3. **Clients 4+ — Full bands ($25K-50K MVP, $150K-300K enterprise).** With case studies in hand, we close at rate.
