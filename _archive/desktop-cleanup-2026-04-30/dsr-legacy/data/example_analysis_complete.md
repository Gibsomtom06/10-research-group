# Complete Analysis of Example Files

## File 1: Crankdat x Tabernacle Marketing Letter (PDF)

This is a 3-page professional marketing expectations document sent to a promoter upon show confirmation. It is the template for what the Show Onboarding Agent should produce.

### Sections and Structure:
1. **Show Header** — Event name, headliner, support, venue, date
2. **Timeline** — Announce date/time, artist presale (with password), promoter presale, general on-sale, all with exact dates/times
3. **Ticket Text** — Exact formatting instructions for how the ticket listing should read
4. **Recommended Budget Allocation** — Announce/On-Sale 40%, Maintenance 10%, Backend 50%
5. **Ad Planning** — Link to a Google Sheets doc with per-phase ad plans
6. **Ad Reporting Doc** — Link to a live Google Sheets reporting doc with deadlines
7. **Social Media Requests** — Specific dates for social support milestones
8. **Content Ideas** — Carousels, artist highlight, support highlight, IG takeovers, countdowns, custom graphics, giveaways
9. **CRM Sends** — Specific email/SMS sends the promoter should execute at each phase with audience targeting
10. **Additional Callouts** — Checklist of questions for the promoter (digital budget, street team, sponsors, university engagement, dark ads)
11. **Approved Assets** — Links to press photos, logo, content/footage, performance photos, approved music

## File 2: Crankdat Atlanta Ad Planning (Google Sheets export — 5 tabs)

This is a multi-tab spreadsheet that serves as the operational ad plan for the show. Each tab is one campaign phase.

### Tab Structure (per phase):
| Column | Content |
|:---|:---|
| Platform | META or TIKTOK |
| Flight Start | Campaign start date |
| Flight Start Time | Exact time (e.g., 9am PT / 12pm ET) |
| Flight End | Campaign end date |
| Flight End Time | Exact time |
| Destination | Where the ad links to (Presale Link, Event Link) |
| Creative | Asset specs (1x1 static, 9x16 static, 1x1 video, 9x16 video) |
| Copy | Ad copy with [CITY], [VENUE], [DATE] placeholders |
| Targeting | Detailed audience layers (engagers, past purchasers, video views, lookalikes, interests, age, geo) |
| Objective | Traffic (Announce), Sales (On-Sale, Maintenance, Backend) |

### Key Observations:
- **Announcement phase** uses Traffic objective (drive to presale signup)
- **On-Sale phase** switches to Sales objective, adds "Excluding Current Purchasers"
- **Backend (Final Push)** includes AD CHECK callouts in red: "swap out least performing asset with approved live clip"
- **Affinity Targeting tab** contains a curated list of ~45 similar artists for interest targeting
- Promoter audiences are marked as "Placeholder" in red — waiting for promoter to provide their custom audiences

## File 3: Crankdat Atlanta Report (Excel — 2 sheets)

This is the performance reporting template that gets filled in during and after the campaign.

### Sheet 1: PAID MEDIA
Organized by phase (Announce, On-Sale, Maintenance, Closeout), each with columns:
- Platform, Budget Spent, Budget Remaining, Impressions, CPC, CPM, CPA/CTR/Additional KPI, Creative Performance, Audiences Targeted, Notes/Callouts

### Sheet 2: CRM
Organized by phase, tracking Email and SMS sends:
- Send Total, Open Rate, Click Rate

### Key Observations:
- Announce phase shows $400 total spend across FB/IG with 33,831 total impressions
- On-Sale phase shows $160 spent with $90 remaining, strong CTR (5.89% FB, 3.75% IG)
- Maintenance and Closeout sections are empty templates — ready to be filled
- This is the exact format our Tour Marketing Agent needs to auto-populate using meta-marketing MCP data + meta-ads-analyzer skill
