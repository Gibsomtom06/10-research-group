# Show Folder Structure

Created in Google Drive under `01_TOUR_STOPS/[MM.DD.YYYY] [City, State] - [Venue Name]`

## 00_CONTROL
- Original offer email (PDF export)
- Negotiation thread (PDF export, if applicable)
- Approval record (Thomas + Leigh + timestamps)
- Competition report (auto-pulled — other shows + festivals that weekend)
- Deal summary sheet (all terms in one doc)

## 01_CONTRACT_&_PAYMENT
- Unsigned contract (sent to promoter)
- Signed contract (uploaded when returned)
- Deposit confirmation
- Final payment confirmation
- Settlement sheet (post-show)

## 02_ADVANCE_&_LOGISTICS
- Advance sheet (venue contact, load-in, stage plot, parking, hospitality)
- Hotel confirmation — [Pending / Confirmed]
- Ground transportation — [Pending / Confirmed]
- Rider sent — [Pending / Confirmed]
- Rider signed + returned — [Pending / Confirmed]
- Technical requirements confirmed — [Pending / Confirmed]
- Green room confirmed — [Pending / Confirmed]

## 03_TRAVEL
- Travel party (Thomas / Andrew / both / neither)
- Flight monitoring log (auto-updated from Google Flights)
- Booked flight + hotel confirmations

## 04_MARKETING
- Dark ad copy (draft → approved)
- Approved content (graphics, video)
- Approved tracks for promoter use (current push single)
- Marketing allocation + spend tracker
- FB event page link + screenshot
- Post-show marketing performance report

## 05_TICKETS
- Sold ticket tracker
- Giveaway ticket log (who received, confirmation numbers)

## 06_SHOW_ASSETS
- Rider PDF (auto-generated with custom Queen line)
- Approved setlist
- Press photo + bio (current approved versions)
