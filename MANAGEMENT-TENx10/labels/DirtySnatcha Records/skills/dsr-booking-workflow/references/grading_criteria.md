# Grading Criteria

Access: Thomas Nalian + Leigh Bray ONLY. Private backend.

## Promoter Grading

Grades auto-calculate from inputs. Cannot be manually overridden. Running average across all shows.

| Input | Values |
|:------|:-------|
| Paid deposit on time | Y / N |
| Paid final payment on time | Y / N |
| Delivered marketing budget | Y / N |
| Created FB event page | Y / N |
| Rider fulfilled | Full / Partial / No |
| Turnout vs projection | Exceeded / Met / Below / Way Below |
| Green room delivered | Y / N |
| Would rebook | Y / N |
| Notes | Free text per show |

**Grade Scale:** A / B / C / D / F — auto-calculated weighted average.

**Alert Rule:** Returning promoter graded D or F → automatic flag when new offer from them enters the queue.

## Venue Grading

Separate from promoter grade. A great venue can have a bad promoter and vice versa.

| Input | Values |
|:------|:-------|
| Production quality | Excellent / Good / Fair / Poor |
| Sound system | Excellent / Good / Fair / Poor |
| Green room quality | Excellent / Good / Fair / Poor |
| Hospitality delivery | Full / Partial / None |
| Capacity vs turnout | Exceeded / Met / Below / Way Below |
| Location/market value | High / Medium / Low |
| Would return | Y / N |
| Notes | Free text per show |

**Alert Rule:** Low-graded venue triggers warning when new offer from same venue enters queue.
