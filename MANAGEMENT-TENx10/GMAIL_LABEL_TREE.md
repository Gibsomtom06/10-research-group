# Gmail Label Tree — DSR / Artists / Publishing

**Apply to:** both `thomas@dirtysnatcharecords.com` AND `thomas@dirtysnatcha.com` (run twice, once per account).
**Where:** Gmail → Settings (gear icon) → "See all settings" → "Labels" tab → "Create new label" for each line below.

Gmail's "Nest label under" option creates the tree. Type the FULL parent path when prompted (e.g. "DSR/Publishing/MLC" creates the MLC label nested under Publishing under DSR automatically).

## What each label is for

| Label | What goes here |
|---|---|
| **DSR** | Top-level catch-all — anything related to the label that doesn't fit a deeper bucket |
| **DSR/Artists/...** | Per-artist correspondence (offers, comms, contracts about that specific artist) |
| **DSR/Publishing** | All publishing rights / royalty correspondence |
| **DSR/Publishing/MLC** | MLC submissions, statements, claims |
| **DSR/Publishing/SoundExchange** | SoundExchange registration + statements |
| **DSR/Publishing/CMRRA** | CMRRA Canada |
| **DSR/Publishing/BMI** | BMI registrations + royalty statements |
| **DSR/Publishing/ASCAP** | ASCAP registrations + royalty statements |
| **DSR/Publishing/International** | PRS (UK), GEMA (DE), SACEM (FR), APRA (AU/NZ), JASRAC (JP), KOMCA (KR), BUMA/STEMRA, STIM, etc. |
| **DSR/Bookings** | Top-level booking correspondence |
| **DSR/Bookings/Offers** | New offers, negotiations, counter-offers |
| **DSR/Bookings/Confirmed** | Confirmed shows — contract through advance |
| **DSR/Bookings/Advance** | Show advance threads (hotel, travel, riders, day-of-show) |
| **DSR/Operations** | Label operational items |
| **DSR/Operations/VMG** | Virgin Music Group distribution comms |
| **DSR/Operations/Vendors** | Mastering, mixing, art, merch vendors |
| **DSR/Operations/Contracts** | Non-artist business contracts (NDAs, vendor agreements, license agreements with third parties) |
| **DSR/Legal** | Legal correspondence (separate from operational contracts) |
| **DSR/Personal** | Non-business correspondence on these accounts (so you can quickly archive it) |
| **_Archive** | Handled, no further action — keep for searchability but out of inbox |
| **_Spam-Train** | Train Gmail's spam classifier — anything you mark here helps |
| **VIP** | Andrew + Thomas Nalian + Lee Bray + key promoters — never goes to spam, always shows in primary |

## Setup order (suggested)

Most painful path first:

1. Top-level: `DSR`, `_Archive`, `_Spam-Train`, `VIP` (4 labels, ~2 min)
2. Artists branch: 5 labels (~2 min)
3. Publishing branch: 7 labels (~3 min)
4. Bookings branch: 4 labels (~2 min)
5. Operations branch: 4 labels (~2 min)
6. Other top-level: `DSR/Legal`, `DSR/Personal` (2 labels, ~1 min)

**Total:** ~12 minutes per account, twice = ~25 minutes total to set up the tree on both accounts.
