# DirtySnatcha Hockey Jersey — Production Spec
**Client:** DirtySnatcha Records (DSR)
**Product:** Custom Hockey Jersey — Pre-Sell Run
**Target:** 100 units before Electric Forest (late June 2026)
**Quality Reference:** CRiiOZ Hockey Jersey (sold out $125 via MHP)

---

## Construction Standard (Mirror CRiiOZ)

- Full sublimation base garment
- Applique patches for key logos (not heat transfer — stitched edges)
- Embroidered elements on top of/alongside sublimation where called out
- Lace-up neck collar
- Authentication tag (sewn in — same as CRiiOZ)
- Each logo layer individually stitched down — no bulk flat print substitution
