How it works

One run a month.

Every custom order in a given month is built in a single production run. That's what keeps a ten-piece crew order priced like a hundred-piece one. Miss the 1st, you're in the next run.

Send the idea

Sketch, reference, or a napkin. We draw it up and quote it.

Approve & pay

Sizes, names and numbers collected. Paid in full — nothing is built on credit.

Orders close

The 1st of the month. Everything that month is built together.

Four weeks

Cut, stitched, embroidered, tagged, laced. Then it ships to you.
